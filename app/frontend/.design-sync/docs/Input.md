Single-line text field, 42px tall, white with a `line` border that turns brand green on focus. Pass `aria-invalid` for the red error border. Standard input props (`value`, `onChange`, `placeholder`, `type`, `disabled`). Wrap it in `Field` for a label and messages. To add a suffix or button inside the field, put it in an `InputBox` and strip the Input down with `className="h-full flex-1 rounded-none border-none bg-transparent px-0 focus-visible:border-none"`.
