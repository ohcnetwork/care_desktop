Inline message box, 12.5px text. `variant="info"` (default) is the green explainer box; `warn` is the amber "act soon" note; `danger` is the red "this can break things" warning. `warn` and `danger` are flex rows, so put a leading lucide icon (`<TriangleAlert className="size-4 flex-none" />`) before the text.
