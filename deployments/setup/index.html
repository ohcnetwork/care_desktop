Device setup

Set up CARE on this device

Do this once so you can open your clinic's CARE securely.

Clinic address: https://example.local

Before you start

Connect to the clinic Wi-Fi, or its wired network. Only continue if your clinic administrator gave you this setup address.

Check the device shown above. Change it if needed.

  1. Download the clinic's security certificate

    Download certificate

    The file is called root.crt. Downloading it is only the first step.

  2. Allow it in Settings

    Keep this page open so you can return to these instructions.

      sh ~/Downloads/install-cert.sh

    1. Open CARE

      After completing the steps above, open CARE. If the sign-in page opens without a security warning, setup is complete.

      Open CARE (new tab)

      Still seeing a warning? Close and reopen your browser, then try again. Do not bypass the warning to enter patient information.

    Advanced setup

    For someone comfortable running scripts. This installer adds the clinic's certificate and may ask for computer administrator approval.

    Download installer 

    sh ~/Downloads/install-cert.sh

    Alternatively, download the certificate, then run the commands for your distribution:

    # Debian / Ubuntu
sudo cp ~/Downloads/root.crt /usr/local/share/ca-certificates/care-root.crt
sudo update-ca-certificates

# Fedora / RHEL
sudo cp ~/Downloads/root.crt /etc/pki/ca-trust/source/anchors/care-root.crt
sudo update-ca-trust

    Some Linux browsers use a separate certificate store. Ask your administrator to configure browser trust if a warning remains.

    Having trouble?

    I cannot find the download

    Look in your browser's Downloads list or your device's Downloads folder for root.crt (or install-cert.sh on Linux).

    My settings look different

    Check the device selected above. Setting names vary by device and version. On Android, search Settings for "CA certificate". On iPhone or iPad, use Safari to download the certificate.

    I need a password, or installation is blocked

    Use your device's passcode or computer administrator password, not your CARE password. If you do not have it, or this device is managed by your organisation, ask your clinic administrator. Do not turn off security protections.

    CARE still shows a security warning

    Downloading the file is not enough: finish the Settings steps, then close and reopen your browser. Try Chrome or Edge on a computer, Chrome on Android, or Safari on iPhone or iPad. If the warning remains, ask your clinic administrator to check the certificate.

    The clinic page does not open

    Check that this device is on the clinic network and the computer running CARE is switched on. If you reached setup using an IP address, ask your administrator to check that the clinic address works on this device.

    Why is this needed?

    Your clinic runs CARE on its own computer. Its security certificate lets this device recognise that computer and open an encrypted connection to CARE, even without internet access.

    A root certificate changes who your device trusts for secure connections. Only install it from your clinic's trusted setup page. If you are unsure, ask your clinic administrator to confirm the certificate before approving it.

    Your browser cannot approve this for you. You need to complete the steps in your device's settings, once on each device.
