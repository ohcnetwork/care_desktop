Device setup

Trust the CARE server

Install the security certificate once so this device can open https://care.local without warnings. Use a Chrome-based browser (Chrome, Edge, Brave) — except on iPhone/iPad, where you must use Safari.

Windows

  1. Tap Download certificate below.
  2. Open the downloaded root.crt and click Install Certificate.
  3. Choose Local Machine → Next (approve the admin prompt).
  4. Select Place all certificates in the following store → Browse → Trusted Root Certification Authorities → OK → Finish.
  5. Fully close and reopen your browser, then visit https://care.local.

macOS

  1. Tap Download certificate below.
  2. Double-click root.crt — Keychain Access opens. Add it to the System keychain (enter your password).
  3. In Keychain Access, double-click CARE Desktop Local CA → expand Trust → set When using this certificate: Always Trust → close.
  4. Reopen your browser and visit https://care.local.

Terminal alternative: sudo security add-trusted-cert -d -r trustRoot -k /Library/Keychains/System.keychain ~/Downloads/root.crt

Linux

Download the certificate, then run the block for your distro:

Debian / Ubuntu

sudo cp ~/Downloads/root.crt /usr/local/share/ca-certificates/care-root.crt
sudo update-ca-certificates

Fedora / RHEL

sudo cp ~/Downloads/root.crt /etc/pki/ca-trust/source/anchors/care-root.crt
sudo update-ca-trust

Restart your browser afterwards, then visit https://care.local.

Android

  1. Tap Download certificate below.
  2. Open Settings → Security (or Security & privacy).
  3. Go to Encryption & credentials → Install a certificate → CA certificate.
  4. Tap Install anyway, then pick the downloaded root.crt.
  5. Open https://care.local in Chrome.

Menu names vary slightly by phone brand.

iPhone / iPad

  1. Tap Download certificate below (use Safari for this step) → Allow.
  2. Open Settings → Profile Downloaded → Install (top right), enter passcode.
  3. Go to Settings → General → About → Certificate Trust Settings.
  4. Turn ON the switch for CARE Desktop Local CA.
  5. Open https://care.local.

The two-step trust toggle is required by Apple for BYOD devices.

🔒 This certificate only lets your device trust this clinic's server on the local network. It grants no access to your device and works fully offline.
